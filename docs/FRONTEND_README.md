# افهمها | Efhama — الصفحة الرئيسية (المرحلة الأولى)

منصة افهمها — مرحلة التطوير الحالية تشمل:

1. **index.html** — الصفحة الرئيسية.
2. **chapters.html** — صفحة الفصول: Breadcrumbs، بطاقات الفصول الأربعة مع نسبة التقدم
   وعدد الدروس المكتملة، بحث فوري، وحالة كل فصل (لم يبدأ / قيد الدراسة / مكتمل).
3. **chapter.html?id=N** — صفحة دروس الفصل: Breadcrumbs كاملة، ترويسة بنسبة التقدم،
   بطاقات الدروس (رقم، وصف، مدة تقديرية، حالة) وزر «ابدأ الدرس / استكمل التعلم»،
   وبحث داخل دروس الفصل.
4. **lesson.html?id=X-Y** — صفحة شرح الدرس (قالب موحد لكل الدروس): قائمة جانبية بأجزاء
   الدرس مع تمييز الجزء الحالي، تقدم قراءة + حفظ آخر موضع، زر الإكمال، السابق/التالي،
   إظهار/إخفاء الملاحظات، أسئلة مراجعة بإجابات قابلة للطي، مصطلحات قابلة للنقر بتعريف فوري،
   وتغيير حجم الخط.

HTML + CSS + Vanilla JS فقط، RTL عربي، بأيقونات SVG (بدون إيموجي)، وضع ليلي/نهاري محفوظ،
وتقدم الطالب يُحفظ في Local Storage بمفتاح موحد (`efhama_completed`) بين الصفحات.

## التشغيل
البيانات الآن في `data/curriculum.json` وتُحمَّل عبر `fetch`، لذا شغّل المشروع عبر خادم ملفات محلي:

```bash
cd efhama-home
python -m http.server 8000
# افتح: http://localhost:8000
```

## البنية
- `index.html` — الهيكل
- `css/styles.css` — كل التصميم (متجاوب + وضعان ليلي/نهاري)
- `js/data.js` — بيانات الفصول والدروس التجريبية (تُستبدل لاحقًا بمحتوى حقيقي)
- `js/app.js` — كل المنطق والتفاعلات

## ملاحظات
- المحتوى تجريبي مؤقت لأغراض التطوير.
- تقدم الطالب محفوظ على جهازه ومتصفحه فقط (Local Storage) — بلا مزامنة بين الأجهزة.
- مفاتيح الحالة: `efhama_completed` (مكتمل) و `efhama_started` (قيد الدراسة) — موحدة بين كل الصفحات.
- مفاتيح صفحة الدرس: `efhama_pos_<id>` (آخر موضع قراءة) و `efhama_fontsize` (حجم الخط).
- كل الأيقونات SVG مدمجة في الكود — لا صور خارجية ولا مكتبات.

## صيغة محتوى الدروس (للمحررين)

`data/lessons/lesson-X-Y.json` — الأنواع المتاحة في `sections[]` (كل نوع يحتاج `heading`):

- `intro` / `text` → `body` (نصوص + يدعم HTML بسيط: `<h3>` عناوين فرعية و`<ul>` قوائم)
- `objectives` / `notes` / `summary` → `items` (مصفوفة نصوص)
- `example` → `items: [{title, body}]`
- `diagram` → `title` + `svg` (سلسلة SVG كاملة)
- `timeline` → `stages: [{label, title, desc}]` — مخطط زمني تفاعلي (النقر يعرض تفاصيل المرحلة)
- `stack` → `layers: [{title, tag?, desc}]` — طبقات متراصة تفاعلية (النقر يعرض وصف الطبقة)
- `matrix` → `x/y {label, levels[]} + cells[][]` — مصفوفة تفاعلية ملوّنة (النقر يعرض تفاصيل الخانة)
- `scenario` → `items: [{situation, options: [{text, correct?, feedback}]}]` — سيناريو تفاعلي بخيارات وتغذية راجعة
- `callout` → `body` + `variant: "info"|"warning"|"success"` — صندوق تنبيه ملوّن (يدعم HTML داخل body)
- `compare` → `a/b: {title, items[]}` — مقارنة ثنائية بعمودين
- `review` → `items: [{q, a}]` سؤال مفتوح، أو `items: [{q, options[], answer, explanation?}]` اختيار من متعدد تفاعلي

ربط مصطلح داخل أي نص: `[[term-id]]` ويجب أن يكون للمصطلح مدخل في `terms[]`.


## المرحلة النهائية (الأنظمة الكاملة)

- **login.html** — دخول مشترك (elgeneral@gmail.com / elgeneral@couned) + حارس على كل الصفحات.
  تنبيه: بوابة أمامية بسيطة وليست حماية حقيقية (المشروع ثابت بدون خادم).
- **quiz.html** — اختبارات: درس (?lesson=X-Y)، فصل شامل (?chapter=N)، تدريب عشوائي (?mode=practice).
  خلط أسئلة واختيارات، تصحيح فوري مع تفسير، نتيجة نهائية، حفظ النتيجة وأفضل نتيجة في Local Storage.
- **glossary.html** — قاموس يجمع كل مصطلحات الدروس الـ14 (109 مصطلحًا فريدًا) مع بحث وتصفية بالفصل.
- **search.html** — بحث شامل في الدروس والمصطلحات والأسئلة (data/search-index.json) + اقتراحات فورية في الهيدر (js/ui.js).
- **faq.html** — المساعد التعليمي المحلي (لا يخترع إجابات) + مؤشر حالة الاتصال.
- **PWA** — manifest.json + service-worker.js (شبكة أولًا مع كاش احتياطي يدعم الروابط بمعاملات ?id=).

## التشغيل
```bash
cd efhama-home
python -m http.server 8000
# افتح: http://localhost:8000  (سيطلب تسجيل الدخول أولًا)
```


## صفحة تسجيل الدخول (معاد تصميمها)

- تخطيط مقسوم: لوحة هوية متدرجة (شعار + «مش هنحفظك المنهج.. هنفهمهولك.» + 3 مميزات) + بطاقة نموذج.
- `css/login.css` (ملف مستقل) + `js/login.js` — لا تغيير في باقي الصفحات.
- تحقق فوري من الحقول، رسائل خطأ واضحة، إظهار/إخفاء كلمة المرور، حالة تحميل، منع الضغط المزدوج.
- Enter ينفذ الدخول. «تذكرني»: localStorage دائم / بدونها sessionStorage (حتى إغلاق المتصفح).
