استعادة حساب مسؤول افهمها - Windows

1) افتحي CMD داخل مجلد المشروع الذي يحتوي package.json.
2) نفذي: npm install
3) نفذي: npm run reset-admin
4) عند سؤال البريد: اضغطي Enter لاستخدام admin@efhama.local، أو اكتبي البريد الموجود فعلًا في قاعدة البيانات.
5) اكتبي كلمة مرور جديدة مرتين. لن تظهر الأحرف على الشاشة عند إدخال كلمة المرور وهذا طبيعي.
6) لا تكتبي npm start قبل ظهور رسالة نجاح الاستعادة والعودة إلى سطر الأوامر.
7) شغلي: npm start
8) افتحي: http://localhost:8000

ملاحظات:
- أداة الاستعادة تستخدم PowerShell لإدخال كلمة المرور بشكل مخفي، ثم تتحقق من تحديث كلمة المرور في قاعدة البيانات.
- إذا كان بريد المسؤول مختلفًا، ستخبرك الأداة بالبريد الموجود بدل إنشاء حساب مسؤول إضافي.
- للحفاظ على بيانات مشروع قديم، احتفظي بمجلد data ولا تستبدليه بقاعدة بيانات فارغة.
- لا تشاركي كلمة المرور مع أي شخص أو داخل المحادثات.
